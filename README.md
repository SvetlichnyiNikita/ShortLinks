# ShortLinks

Консольный сервис коротких ссылок на Java 17. Вставьте короткую ссылку в консоль, и исходный адрес откроется в браузере. Для перехода UUID не нужен. Владелец видит свои ссылки, меняет адрес назначения и лимит переходов.

## Запуск

Нужны JDK 17 и Maven 3.8+. В корне проекта выполните:

```shell
mvn clean verify
java -jar target/shortlinks.jar
```

В IntelliJ IDEA откройте проект по `pom.xml`, выберите JDK 17 и запустите `com.example.shortlinks.Main`. Рабочая папка — корень проекта. Для открытия ссылок нужен браузер по умолчанию. Само приложение использует стандартную библиотеку Java. JUnit и Checkstyle Maven скачает при первой сборке.

## Пример

Вставьте полный URL в консоль и нажмите Enter. Например, `https://github.com/SvetlichnyiNikita/ShortLinks` сразу даст короткую ссылку с лимитом из настроек.

Чтобы задать лимит в два перехода, используйте команду:

```text
create https://example.org/articles/java 2
```

При создании первой ссылки программа выдаст короткий адрес и ваш UUID. Сохраните UUID для следующего входа. Допустим, вы получили `https://s.local/1`. Следующие команды покажут ссылку, откроют исходную страницу в браузере и выведут обновлённый счётчик:

```text
list
https://s.local/1
list
```

После первого перехода `list` покажет `1/2`. Второй переход откроет страницу и исчерпает лимит. Программа сообщит об этом владельцу. С третьей попытки ссылка уже недоступна. Адреса `s.local` распознаёт консоль приложения. Вставляйте их в строку с приглашением `>`.

Команды можно вводить в любом регистре: `list`, `LIST` и `List` работают одинаково.

| Команда | Действие |
| --- | --- |
| `create URL [лимит]` | Создать короткую ссылку для полного HTTP(S)-адреса. Если пропустить лимит, программа возьмёт его из настроек. |
| `list` | Показать свои активные ссылки, счётчики и время окончания в UTC. |
| `https://s.local/код` | Открыть исходный URL в браузере. При ошибке запуска браузера счётчик сохраняет прежнее значение. |
| `limit ссылка число` | Изменить общий лимит. Новое значение должно превышать число учтённых переходов. |
| `target ссылка URL` | Изменить адрес назначения с сохранением счётчика и срока действия. |
| `delete ссылка` | Удалить свою ссылку. |
| `logout` | Выйти. Следующая команда создания выдаст UUID нового пользователя. |
| `id` | Показать UUID текущего пользователя. Сохраните его для следующего входа. |
| `login UUID` | Вернуться к своим ссылкам и прочитать пропущенные уведомления. |
| `help` | Показать все команды. |
| `exit` | Завершить программу. Выполнять `logout` перед этим не нужно. |

## Настройки и хранение

В `shortlinks.properties` параметр `ttl.seconds` задаёт срок действия новых ссылок в секундах (по умолчанию 86400), а `click.limit` — лимит по умолчанию (10). Оба значения — целые положительные числа. После изменения настроек перезапустите программу. У уже созданных ссылок сохраняются прежние срок и лимит.

Короткий код — порядковый номер в системе счисления с основанием 36. Счётчик сохраняется вместе с данными, поэтому даже после удаления ссылки и перезапуска её код не будет выдан повторно. Истёкшие ссылки удаляются при запуске и раз в секунду во время работы. При переходе срок проверяется сразу. Уведомления сохраняются для владельца, даже когда в консоли работает другой пользователь.

## Устройство

* `Main` читает настройки, подключает системный браузер и запускает периодическую очистку.
* `Console` разбирает команды, запоминает текущего пользователя и выводит ответы.
* `ShortLink` хранит владельца, адрес, срок действия и счётчик одной ссылки.
* `LinkService` выдаёт коды, проверяет права и ограничения, учитывает переходы и формирует уведомления. Переход записывается на диск до открытия браузера. Если браузер сообщает об ошибке запуска, сервис восстанавливает счётчик.
* `LinkStore` сохраняет состояние в `data/links.tsv` через временный файл и атомарную замену. Одну папку данных обслуживает один экземпляр приложения. Папка создаётся при запуске и исключена из Git.

## Тестирование

`mvn test` запускает тесты JUnit. Среди сценариев — последний разрешённый переход, истечение срока, сбой записи и смена владельца в консоли. Тесты используют временную папку данных. Для проверки открытия ссылки они сверяют адрес, который приложение передало браузеру.

`mvn clean verify` также собирает исполняемый JAR и проверяет исходники и тесты через Checkstyle. GitHub Actions выполняет эту команду при push и pull request.
